Parameter Calculator

VRCSDKのAdvanced Options（Bit Width・Representation）に対応。
パラメータの種類・ビット数・符号を選ぶと、値域と精度を自動計算します。

VRChatの同期パラメータで設定可能な 2～8 bit に対応。Floatは符号あり／なしで値の刻み幅も変わります。

計算結果

Int · 8 bit · 符号なし

最大値（MAX）255
表現可能な整数の個数256
値の間隔（刻み幅）1
ビット構成のイメージ8 bits
数値用ビット符号ビット（Intで符号ありの場合）

※ このツールはExpression Parametersの同期時の表現を計算します。FloatはIEEE 754の浮動小数点ではなくVRCSDKの固定範囲量子化です。ローカルのAnimatorではFloatは通常の32bit浮動小数点として扱われます。
